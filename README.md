# DevProject

A project management REST API built with TypeScript, Fastify,
PostgreSQL, and JWT authentication.

## Features

- User authentication
- JWT-based authorization
- Project creation and management
- PostgreSQL relational database
- Request validation
- Protected API routes

## Tech Stack

- TypeScript
- Node.js
- Fastify
- PostgreSQL
- JWT

## Running Locally

npm install
npm run dev
